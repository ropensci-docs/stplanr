# Extract nodes from route network

Extract nodes from route network

## Usage

``` r
rnet_get_nodes(rnet, p = NULL)
```

## Arguments

- rnet:

  A route network of the type generated by
  [`overline()`](https://docs.ropensci.org/stplanr/reference/overline.md)

- p:

  A point represented by an `sf` object the will split the `route`
