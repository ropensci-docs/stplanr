# Convert a series of points, or a matrix of coordinates, into a line

This function makes that makes the creation of `sf` objects with
LINESTRING geometries easy.

## Usage

``` r
points2line(p)
```

## Arguments

- p:

  A spatial (points) obect or matrix representing the coordinates of
  points.
